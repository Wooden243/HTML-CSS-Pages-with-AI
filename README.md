 守ってほしい技術要件


セマンティック HTML — 第 2 章で扱った <header> / <nav> / <main> / <section> / <footer> を適切に使う。<div> だけで組まない。

Tailwind CSS のみ — 自前の <style> や CSS ファイルを書かず、Tailwind ユーティリティクラスだけで完成させる。CDN セットアップを使う。

レスポンシブ対応 — スマホ（〜640px）/ タブレット（768px〜）/ PC（1024px〜）の 3 段階でレイアウトが破綻しない。md: / lg: プレフィックスで切り替える。

モバイルファースト — 基本クラスはモバイル向け、md: 以上で広い画面向けの上書きを足す方針で書く（第 6 章で扱った思考）。

主要 CTA に hover: を付ける — ボタンにマウスを乗せたとき、色や影が変わる演出を入れる。

画像は使わない — 写真や PNG のアイコンは使わず、文字 / 絵文字 / グラデーション背景だけで表現する。実装の本質に集中するためで、画像準備は実務に進んでから扱う。
